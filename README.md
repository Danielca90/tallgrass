# Tallgrass

A GBA-style creature-catching RPG written in plain Java (no libraries). Every map, creature,
sprite, tile and sound-free pixel is generated in code. The world builds itself as you explore:
which direction you walk from home decides what you find.

- **North**: highlands, then snowfields (Stone, Gale, Frost types)
- **South**: the coast (Tide, Volt types)
- **East**: dunes, then canyons (Ember, Stone, Iron types)
- **West**: forest, then swamp (Bloom, Shade, Spirit types)

Creatures get stronger the farther you go. Towns have a healing center (nurse + shop), houses,
and most have a gym leader who gives a badge.

## Controls

| Key | Button |
| --- | --- |
| Arrow keys / WASD | D-pad |
| Z, Space or J | A (talk, confirm) |
| X, Esc or K | B (back, hold to run) |
| Enter | Start (menu) |
| Shift or R | Toggle auto-run (Fast Boots) |

## Quests

World of Warcraft style. People with a yellow **!** over their head have a quest for you; a grey **?** means
it's in progress, a yellow **?** means it's ready to turn in. Accepted quests show in the tracker at the
top right and in **Start → QUESTS**.

- **Story:** Professor Alder's chain: tall-grass training, a parcel for the northern town's nurse, your first
  badge, field research (catch 8 kinds), four badges.
- **Side quests:** every town has a quest giver (bigger towns have two) and some routes have travellers.
  They're generated from where they stand: defeat creatures of a local type, collect drops (like Frost
  Shards from Frost-types), catch a creature from a neighbouring biome, beat trainers, deliver a letter
  to another town's nurse, or scout an area two steps away. Rewards scale with distance from home.

## Graphics and texture packs

The overworld runs at 480x320 with 32px tiles; menus and battles still use the classic 240x160 look
(scaled 2x) until they get their HD pass. Every texture is generated by code (`HdArt.java`) and **baked
into PNGs at build time** (`./gradlew bakeTextures`, run automatically by `jar`), one file per texture,
like Minecraft's block textures.

To make your own texture pack, export the defaults and edit any PNG:

```bash
java -cp build/libs/Tallgrass.jar tallgrass.TextureBaker ~/.tallgrass/resourcepack/textures
```

The game uses `~/.tallgrass/resourcepack/textures/<name>.png` when it exists, then the baked texture
in the jar, then generates it in code. A missing texture shows Minecraft's magenta checkerboard.

## Build and run

Homebrew's JDK is "keg-only", so macOS can't see it until you link it once:

```bash
sudo ln -sfn /opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk /Library/Java/JavaVirtualMachines/openjdk-21.jdk
```

After that, `java`, `./gradlew` and double-clicking `Tallgrass.jar` all work. `Tallgrass.app` works either way, since it carries its own Java.

Needs JDK 21+. `gradle.properties` points Gradle at Homebrew's `openjdk@21`; change that path if your JDK lives elsewhere.

```bash
./gradlew run          # play from source
./gradlew jar          # build/libs/Tallgrass.jar  (double-click it, or: java -jar build/libs/Tallgrass.jar)
./gradlew macApp       # build/app/Tallgrass.app   (bundles its own Java runtime)
```

## Starting out

Like Minecraft: **Singleplayer → Create New World**. Pick a world name, an optional seed (a number,
any text, or blank for random — the same seed always builds the same world and creatures), your
trainer's name and look. You wake up at home; Mom sends you to Professor Alder's lab, where you choose
your partner from three orbs on his table. The town exits stay closed until you have one.

Each world is its own folder under `~/.tallgrass/worlds/`. The game autosaves whenever you change
area; **Start → SAVE & QUIT** returns to the title.
